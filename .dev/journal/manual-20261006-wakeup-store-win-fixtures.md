# Manual fix: wakeup_store test fixtures used colon-bearing session ids (Windows os error 123)

- issue:        #139 (windows CI long-red, fixture-only)
- baseline:     c387f088
- mode:         orchestrator-direct (3 string literals in one test module)
- verdict:      completed

## Root cause

`src/tasks/wakeup_store.rs` built session directories named
`2026-01-01T00:00:00Z-slug` / `…-live` in three tests. Windows forbids `:` in
file/dir names, so `create_dir_all` returned
`Error::Storage { message: "… create …\sessions\C--…-ws\2026-01-01T00:00:00Z-slug: The filename, directory name, or volume label syntax is incorrect. (os error 123)" }`.
Real session ids are generated by `session::filesystem_safe_timestamp()`
(`chrono_lite_now().replace(':', "-")`, `src/session/mod.rs:353`), so only the
fixtures were invalid — the store's naming layer is fine and was left alone.

## Change

`src/tasks/wakeup_store.rs` — fixture ids now match the real id shape:

- `take_due_in_workspace_consumes_the_record` (:372)
- `take_due_in_workspace_ignores_future_records` (:399)
- `take_due_in_workspace_skips_a_session_held_by_a_live_process` (:416)

`2026-01-01T00:00:00Z-slug|live` → `2026-01-01T00-00-00Z-slug|live`.
No product code touched; no sanitisation added to the store.
